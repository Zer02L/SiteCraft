# 📁 Public Media & Documentation Assets

Директория `public/` предназначена исключительно для медиа-материалов документации репозитория (скриншоты для README на GitHub, превью и баннеры).

Веб-ассеты сайта (стили Tailwind, иконки, графика тем) хранятся в [`ui/assets/`](../ui/assets) и автоматически вшиваются в бинарник через `//go:embed` ([`ui/embed.go`](../ui/embed.go)).
