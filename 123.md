  ### 4. Мультисайтовость (Multi-tenancy / White-label)
  Сейчас один инстанс — это один сайт. Превращение в генератор/платформу:
  1. Режим Multi-domain (SaaS в одном бинарнике):
      • PocketBase определяет сайт по заголовку Host (домену, например notary.ru или virtuality.app).
      • В зависимости от домена берется свой конфиг из коллекции tenants (или отдельная SQLite база tenant_1.db).
  2. Режим Static Site Export (генератор статики):
      • Добавить CLI-команду ./server export --preset=cyber --out=./dist
      • Рендерит все страницы в плоский HTML/CSS, чтобы сайт можно было выгрузить на GitHub Pages, Cloudflare Pages или дешевый FTP без сервера.

  ### 5. CLI-генератор новых сайтов (sitecraft-cli / fleet.sh)

  У вас уже есть init-project.sh, но можно оформить это как инструмент разработчика:

    sitecraft new my-agency --preset=cyber --theme=dark
    sitecraft add-block testimonials
    sitecraft export-theme

  • Инструмент сам разворачивает чистую БД SQLite, накатывает выбранные миграции и скачивает пресет.

  [x] СТАТУС: ВЫПОЛНЕНО в скрипте fleet.sh:
      • ./fleet.sh create <site-id> --preset=<niche> [--theme=<theme>] [--port=<port>] — моментальное создание и накатывание пресета в отдельную БД.
      • ./fleet.sh start / stop / restart <site-id> — фоновое управление инстансами.
      • ./fleet.sh list — мониторинг статусов, портов и PID.
      • ./fleet.sh backup <site-id> — экспорт сайта и базы в архив .tar.gz для передачи клиенту под ключ.
      • ./fleet.sh export <site-id> [out] — экспорт инстанса в чистую статику (HTML/CSS).
