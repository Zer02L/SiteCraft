# 🛡️ SiteCraft Server Watchdog (Zero-RAM Linux VPS Monitor)

Автономный фоновый сторож сервера на Bash с отправкой алертов в Telegram.

## Особенности
* **0 МБ RAM в фоне**: не висит постоянным демоном, а запускается по расписанию cron на 0.1 секунды.
* **4 критические проверки**:
  1. **Диск (Root `/`)**: предупреждает при заполнении > 85%.
  2. **Оперативная память (RAM)**: предупреждает, если свободной памяти осталось < 10%.
  3. **Нагрузка на CPU**: рассчитывает Load Average относительно количества физических ядер.
  4. **Статус сервиса `sitecraft`**: если служба упала, отправляет алерт и пытается автоматически перезапустить `systemctl restart sitecraft`.
* **Антиспам-кулдаун (2 часа)**: если диск заполнен на 86%, скрипт не будет заваливать Telegram сообщениями каждые 10 минут, а пришлет повтор только через 2 часа.
* **Уведомления о восстановлении (Auto-Recovery)**: когда проблема решена (диск очищен или сервис поднят), отправляет зеленое сообщение `✅ ВСЁ В НОРМЕ`.

## Быстрая установка на сервере

### Шаг 1. Настройка окружения
```bash
cd /var/www/sitecraft/deploy/monitoring
cp .watchdog.env.example .watchdog.env
nano .watchdog.env
```
Заполните `TG_BOT_TOKEN` и `TG_CHAT_ID`.

### Шаг 2. Выдача прав на исполнение
```bash
chmod +x /var/www/sitecraft/deploy/monitoring/watchdog.sh
```

### Шаг 3. Тестовый запуск
```bash
/var/www/sitecraft/deploy/monitoring/watchdog.sh
```
*(Если все параметры в норме, скрипт завершится без сообщений; если нужно протестировать доставку в Telegram, временно задайте в `.watchdog.env` `DISK_THRESHOLD=10` и запустите снова).*

### Шаг 4. Добавление в Crontab
Откройте планировщик от имени `root` (чтобы сторож мог проверять и перезапускать systemd-службу):
```bash
sudo crontab -e
```
Добавьте запуск каждые 10 минут:
```crontab
*/10 * * * * /var/www/sitecraft/deploy/monitoring/watchdog.sh > /dev/null 2>&1
```
