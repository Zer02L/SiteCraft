# Project Brief: Scrollytelling Interactive Site

## 1. Общая концепция
- **Название / Тематика:** Нотариальная контора (Сайт-визитка частного нотариуса).
- **Ключевая аудитория:** Граждане и юридические лица, оформляющие сделки с недвижимостью, заверяющие доверенности, вступающие в наследство, заверяющие корпоративные решения бизнеса.
- **Главная цель:** Формирование доверия, демонстрация официального статуса и регламента, быстрая запись на прием по слотам без очередей.

## 2. Сюжетная линия (Chapters & Scrollytelling)
- **Screen 1 (Hero):**
  - *Посыл:* «Нотариальная контора • Законная защита прав и чистота сделок».
  - *Элементы:* Лицензия, адрес в центре, кнопка «Записаться на приём».
  - *Фон:* Строгий минималистичный Swiss Style с аккуратной фоновой сеткой и тонким спотлайтом.
- **Screen 2 (Ключевые показатели — Cinematic Odometer):**
  - *Метрики:* 15+ лет безупречной нотариальной практики, 25 000+ удостоверенных актов, 100% электронная подача в Росреестр / ФНС.
- **Screen 3 (Нотариальные услуги — Spotlight / Sticky Cards):**
  - *Блоки:* Недвижимость (купля-продажа, дарение, ипотека), Наследственные дела, Доверенности и согласия, Юридическим лицам (собрания, вход участников, залог долей).
- **Screen 4 (Порядок обращения и регламент — Sticky Stack):**
  - *Шаги:* 1. Запись и отправка сканов документов → 2. Юридическая экспертиза → 3. Визит и удостоверение за 15 минут → 4. Электронная регистрация в ведомствах.
- **Screen 5 (Финал: Запись, Расписание, Карта):**
  - *Компоненты:* Интерактивная запись по свободным слотам времени (`booking`), режим работы без очередей (`schedule`), схема проезда и парковка (`map`).

## 3. Визуальный стиль и архитектура
- **Цветовая палитра:** Строгий швейцарский минимализм (Swiss Style) — глубокий угольный графит (`#0f172a`), чистый белый фон поверхностей, золотисто-платиновый сдержанный акцент (`#c5a880` / `#d4af37`), нейтральный текст.
- **Шрифтовая пара:**
  - Заголовки: строгий выразительный гротеск с прецизионной геометрией (Inter / Helvetica Neue / Barlow).
  - Текст: разборчивый нейтральный санс-сериф.
- **Динамика анимаций:**
  - **Zero-GSAP Edition:** чистый CSS (`position: sticky`, `@keyframes`), Motion One для субпиксельного скраббинга, Alpine.js для микро-интеракций.
  - Обязательная поддержка ГОСТ `body.a11y-mode` и `@media (prefers-reduced-motion: reduce)`.
