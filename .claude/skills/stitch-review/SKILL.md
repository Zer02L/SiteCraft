---

### Review Procedure:
1. Запусти локальный сервер проекта (например, `npm run dev` или `python -m http.server`).
2. С помощью Playwright / Puppeteer сделай скриншоты страниц на трех брейкпоинтах:
   - Mobile: 390x844
   - Tablet: 768x1024
   - Desktop: 1440x900
3. Сравни полученные изображения с макетом Stitch и файлом design.md.
4. Выведи отчет с сортировкой проблем (Critical / Moderate / Minor):
   - Переполнение контейнеров и сломанная верстка.
   - Несоответствие типографики, цветов и отступов.
5. Автоматически внеси исправления в CSS/компонентах проекта.
