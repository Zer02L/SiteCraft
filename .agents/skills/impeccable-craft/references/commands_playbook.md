# Плейбук команд Impeccable-Craft (SiteCraft Edition)

Дизайн-вокабуляр и алгоритмы исполнения команд для кодинг-агента при разработке интерфейсов на стеке **Go + Templ + Tailwind CSS v4 + Alpine.js + HTMX**.

---

## 🛠️ Сводка команд

| Команда | Назначение | Фокус изменений |
|---|---|---|
| `/impeccable-craft shape [цель]` | Проектирование структуры UI перед написанием кода | Архитектура экрана, выбор макроструктуры, информационная иерархия, сетка данных. |
| `/impeccable-craft critique [цель]` | Структурированная критика дизайна по эвристикам | Поиск UX-багов, оценка ритма, выявление AI-slop с классификацией P0–P3. |
| `/impeccable-craft audit [цель]` | Технический аудит и запуск детерминированного чекера | Запуск `check_slop.py`, проверка доступности (ГОСТ), мобильной ширины (390px), DOM-маппинга. |
| `/impeccable-craft polish [цель]` | Финишная доводка и микро-полировка перед релизом | Выравнивание отступов, радиусов, рамок (`border-content/10`), состояний ховера и переходов. |
| `/impeccable-craft bolder [цель]` | Усиление выразительности и контраста | Увеличение типографического контраста, акцентный цвет, динамика сетки, смелые акценты. |
| `/impeccable-craft quieter [цель]` | Снижение визуального шума и перегрузки | Успокоение кричащих элементов, удаление лишних плашек, замена рамок на отступы. |
| `/impeccable-craft distill [цель]` | Беспощадное упрощение до голой функции | Удаление декоративного балласта, лишних иконок, пустых бейджей и вложенных оберток. |
| `/impeccable-craft typeset [цель]` | Доводка типографики и читаемости | Шрифтовая шкала, трекинг, интерлиньяж (`leading`), ограничение ширины строки (`max-w-prose`). |
| `/impeccable-craft document` | Фиксация дизайн-системы в `DESIGN.md` | Извлечение токенов из `presets/*.json` и `tokens.css` в устойчивый документ контекста. |

## 📋 Подробные сценарии выполнения

### 1. `/impeccable-craft shape [цель]`
**Когда применять:** Перед версткой новой страницы, секции или сложного компонента.
**Алгоритм действий:**
1. Проанализировать задачу: кто целевой пользователь (B2B заказчик, розничный клиент, администратор)?
2. Выбрать тип поверхности:
   * **Persuade (Лендинг):** сфокусирован на ценностном предложении, фактах, социальных доказательствах и CTA.
   * **Operate (Интерфейс/ЛК):** высокая плотность информации, табличные данные, быстрые фильтры, удобные формы.
   * **Read (Статья/Кейс):** безупречная типографика, фокус на чтении, комфортный интерлиньяж.
3. Сопоставить с каталогом макроструктур Hallmark (`hallmark-craft/references/macrostructures_catalog.md`).
4. Набросать каркас секций с обязательными атрибутами `data-component` и `data-source`.

---

### 2. `/impeccable-craft polish [цель]`
**Когда применять:** Верстка готова функционально, но выглядит сырой, несобранной или «дефолтной».
**Алгоритм действий:**
1. **Пространственный ритм:** Проверить симметрию паддингов внутри карточек (`p-6 sm:p-8`), отступы между заголовком и текстом (`space-y-3` или `gap-4`).
2. **Границы и разделители:** Заменить дефолтные тяжелые границы на утонченные `border border-content/10` или `divide-y divide-content/10`.
3. **Радиусы скруглений:** Привести к токенам проекта (`rounded-(--radius-card)` или `rounded-(--radius-btn)`).
4. **Микроинтерактивность:** Добавить тактильные ховер-эффекты: `hover:border-content/25 transition-all duration-200 ease-out`.
5. **Скомпилировать и проверить:**
   ```bash
   templ generate && tailwindcss -i ./ui/assets/input.css -o ./ui/assets/styles.css --minify
   ```

---

### 3. `/impeccable-craft bolder [цель]`
**Когда применять:** Интерфейс выглядит «серым», робким, шаблонным или скучным.
**Алгоритм действий:**
1. **Типографический взрыв:** Увеличить размер ключевого заголовка (`text-4xl md:text-6xl font-black tracking-tight`).
2. **Контраст фона:** Добавить глубокий фоновый блок для чередования ритма страницы (`bg-surface-muted` или полноэкранный `Band` в инверсном цвете).
3. **Акцентный цвет:** Вывести один элемент (главный CTA, акцентную метрику) в цвет `--color-accent` или `--color-primary`.
4. **Сетка:** Преобразовать монотонный список в асимметричный Bento-grid с одной доминирующей большой карточкой.

---

### 4. `/impeccable-craft quieter [цель]`
**Когда применять:** Страница рябит в глазах, слишком много разноцветных бейджей, кнопок и рамок.
**Алгоритм действий:**
1. **Снижение насыщенности:** Превратить пестрые цветные бейджи в монохромные: `bg-content/5 text-content-muted border border-content/10`.
2. **Устранение рамок:** Убрать границы у второстепенных карточек, оставив разделение пространством (`gap-8`).
3. **Вторичные кнопки:** Заменить яркие кнопки на приглушенные (`variant="outline"` или `variant="ghost"`).
4. **Удаление орбов:** Стереть фоновые цветные градиенты и пятна.

---

### 5. `/impeccable-craft distill [цель]`
**Когда применять:** Страница перегружена «AI-мусором»: искусственные бейджи «Новинка!», бессмысленные иконки у каждого пункта, декоративные стрелочки.
**Алгоритм действий:**
1. Удалить все иконки, которые не добавляют функциональной информации.
2. Удалить вложенные карточки внутри карточек.
3. Сократить текст до сути: оставить только факты, цифры и действия.
4. Оставить один первичный CTA на видимый экран.

---

### 6. `/impeccable-craft audit [цель]`
**Когда применять:** Перед коммитом, пулл-реквестом или сдачей этапа работ.
**Алгоритм действий:**
1. Запустить локальный чекер:
   ```bash
   python3 .agents/skills/impeccable-craft/scripts/check_slop.py [target]
   ```
2. Проверить вердикт:
   * **P0 (Блокер):** Горизонтальный скролл на 390px, удаление outline клавиатуры без ring.
   * **P1 (Качество):** Захардкоженные HEX, AI-градиенты, маркетинговые клише.
   * **P2 (Полировка):** Медленные анимации, тесные паддинги.
3. Проверить `make check` (компиляция шаблонов Templ, валидность Go-кода).
