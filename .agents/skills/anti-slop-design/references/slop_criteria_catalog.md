# Полный каталог критериев и паттернов AI Slop в веб-дизайне

> **AI Slop в веб-дизайне** — это усредненный, клишированный визуальный и смысловой шум, генерируемый нейросетевыми агентами (v0, Claude, Cursor, ChatGPT, Lovable) из-за переобучения на однотипных шаблонах Tailwind UI, Dribbble и лендингах SaaS стартапов 2022–2024 годов.
>
> Slop не выглядит «сломанным» — он выглядит опрятно, но абсолютно безвкусно, взаимозаменяемо, псевдо-технологично и оторван от реальной задачи пользователя.

Данный каталог систематизирует **все известные критерии визуального AI Slop**, объясняет механику ошибки и предоставляет строгие правила их исключения.

## ⚡ Категория 5: Анимационная усталость и поломки (Motion & UX Slop)

| ID | Паттерн (AI Slop) | Сигнатуры в коде | Почему это Slop | Альтернатива высокой культуры (Craft Fix) |
|---|---|---|---|---|
| **AS-MOT-01** | **Ловушка скрытого контента (Invisible Load)** | `opacity-0 translate-y-8` на всех блоках в ожидании скролла через JS | Если JS заблокирован, медленно грузится или упал с ошибкой — пользователь видит пустой экран. Ухудшает SEO. | Progressive Enhancement: контент отрендерен на сервере и виден сразу. Анимация мягко обогащает интерфейс, но не прячет его. |
| **AS-MOT-02** | **Вязкие затянутые переходы** | `transition: all duration-500`, `duration-700` на кнопках и ссылках | Ощущение «ватного», тормозящего интерфейса. Пользователь ждет отклика на клик. | Тактильный микро-отклик: `duration-150` .. `duration-200` с кривой `ease-out`. Никогда не использовать `transition: all`. |
| **AS-MOT-03** | **Анимация свойств Reflow** | Переходы по `height`, `width`, `top`, `left`, `margin`, `padding`, `filter: blur()` | Вызывает пересчет макета страницы (Layout Reflow), роняет FPS до 20–30 на мобилках. | Анимировать **строго аппаратные GPU-свойства**: `transform` (`translate3d`, `scale`) и `opacity`. |
| **AS-MOT-04** | **Лагающие курсоры-прожекторы (Spotlight)** | Следящие за мышью радиальные градиенты на JS с `mousemove` слушателями | Отвлекают от чтения контента, греют процессор ноутбука и забивают event loop. | Использовать нативный CSS `:hover` на интерактивных элементах без глобальных слушателей курсора. |
| **AS-MOT-05** | **Игнорирование prefers-reduced-motion** | Бесконечно вращающиеся плашки, летающие частицы без медиа-запроса | Вызывает головокружение и тошноту у людей с вестибулярными расстройствами. | Обязательное отключение или минимизация анимаций: `@media (prefers-reduced-motion: reduce) { *, ::before, ::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }`. |

## 🛡️ Категория 6: Доступность и анти-паттерны взаимодействия (A11y Violations)

| ID | Паттерн (AI Slop) | Сигнатуры в коде | Почему это Slop | Альтернатива высокой культуры (Craft Fix) |
|---|---|---|---|---|
| **AS-A11Y-01** | **Срезанный фокус клавиатуры** | `focus:outline-none` без `focus-visible:ring` | Делает сайт полностью недоступным для пользователей клавиатуры (нарушение ГОСТ/WCAG). | Явное контрастное кольцо фокуса: `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2`. |
| **AS-A11Y-02** | **Кнопки-иконки без текстовых меток** | `<button><svg>...</svg></button>` без подписи | Скринридер читает как «Кнопка, не названо». Слепой пользователь не может управлять сайтом. | Обязательный `aria-label="Название действия"` или внутренний скрытый спан `<span class="sr-only">Закрыть окно</span>`. |
| **AS-A11Y-03** | **Микроскопические зоны клика** | Кнопки и ссылки размером 20–30px на мобильных | Промахи пальцем, раздражение пользователя, высокий процент случайных кликов. | Интерактивная область касания минимум 44×44px (WCAG 2.5.5 Target Size). |
| **AS-A11Y-04** | **Передача статуса только цветом** | Красный/зеленый кружок без пояснительного текста или значка | Недоступно для людей с дальтонизмом (8% мужчин). | Сочетание цвета с пиктограммой (галочка/крестик) и текстовой подписью статуса. |
