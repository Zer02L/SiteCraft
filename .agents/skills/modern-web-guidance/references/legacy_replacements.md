# Справочник прямых замен (Legacy -> Modern Platform)

Таблица перехода от устаревших JavaScript/CSS практик к нативным возможностям современных браузеров в **SiteCraft**.

---

| № | Устаревший паттерн (Legacy) | Современный стандарт (Modern Web) | Преимущество в SiteCraft |
|---|---|---|---|
| 1 | **Оверлей модалки дивами**: `<div class="fixed inset-0 z-50 bg-black/50">` | Нативный тег **`<dialog>`** с методом `.showModal()` | Автоматический Top Layer (нет войн z-index), нативный фокус-трап и клавиша Esc. |
| 2 | **Alpine `@click.outside` для меню** | Нативный атрибут **`popover="auto"`** + `popovertarget` | Браузер сам закрывает меню при клике в любое другое место (Light Dismiss). Ноль JS-логики. |
| 3 | **Библиотеки Popper.js / Tippy.js** | **CSS Anchor Positioning** (`anchor-name`, `position-anchor`) | Позиционирование всплывающего окна относительно кнопки прямо в CSS без `getBoundingClientRect()`. |
| 4 | **JS таймауты для скрытия анимаций** (`setTimeout(..., 300)`) | **`@starting-style`** + `transition-behavior: allow-discrete` | Плавная CSS-анимация появления и скрытия элементов с `display: none`. |
| 5 | **JS-слушатель ресайза** (`window.addEventListener('resize')`) | **CSS Container Queries** (`@container` в Tailwind v4) | Компоненты адаптируются к своему родителю. Можно поместить Bento-карточку в колонку любой ширины. |
| 6 | **Хак для соотношения сторон** (`pt-[56.25%]`, `pb-[75%]`) | Нативное CSS-свойство **`aspect-ratio`** (`aspect-video`) | Чистый семантический CSS, не требующий вспомогательных псевдоэлементов. |
| 7 | **JS класс на body при скролле** (`is-scrolled`, `has-modal`) | CSS псевдокласс **`:has()`** | Выбор родителя по состоянию дочерних элементов: `body:has(dialog[open])`. |
| 8 | **JS ленивая загрузка картинок** (`lazysizes.js`, `data-src`) | Нативные атрибуты **`loading="lazy"`** и **`decoding="async"`** | Браузер сам откладывает сетевой запрос до приближения картинки к экрану. Минус 10 КБ JS. |
| 9 | **Медленная загрузка LCP-баннера** (задержка открытия страницы) | Атрибут **`fetchpriority="high"`** на Hero-изображении | Браузер поднимает приоритет сетевого стрима в HTTP/2-3, ускоряя LCP на 300–800мс. |
| 10 | **Тяжёлые библиотеки анимаций** (GSAP ~80 КБ, Anime.js) | Аппаратный **CSS (`transform`, `opacity`)** + **Motion One (~3 КБ)** | 60 FPS, экономия трафика, нулевая блокировка главного потока процессора (INP < 100ms). |
| 11 | **Кросс-документные SPA-роутеры** (React Router, Barba.js) | **HTMX `transition:true`** + нативный **View Transitions API** | Плавные морфинг-анимации страниц при серверном рендеринге Go Templ. |
| 12 | **JS валидация с красным текстом во время ввода** | Псевдокласс **`:user-invalid`** | Форма ругается только тогда, когда пользователь действительно ошибся и покинул поле. |
| 13 | **Сложные выравнивания карточек через JS** | **CSS Subgrid** (`grid-template-rows: subgrid`) | Заголовки, описания и кнопки карточек выстраиваются по сетке родителя автоматически. |
| 14 | **Синхронные циклы, вешающие UI** | **`await scheduler.yield()`** или **`requestIdleCallback`** | Плавный инпут (INP), разбиение тяжелых задач на микротиковые порции. |
| 15 | **Блокирующий `@import url('fonts...')` в CSS** | Локальные **WOFF2**-файлы + `<link rel="preload" as="font">` | Zero External CDN, моментальный показ текста без FOUT/FOIT. |
