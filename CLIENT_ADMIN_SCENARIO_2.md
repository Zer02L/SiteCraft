# 🚀 Дорожная карта развития клиентской админки: Сценарий 2 (Кабинет управления контентом и каталогом)

Данный документ фиксирует спецификацию и план расширения клиентской панели управления для SiteCraft Engine.

---

## 🎯 Цель этапа
Предоставить клиенту автономный инструмент для ведения каталога товаров/услуг, управления медиа-файлами, отзывами клиентов и визуальным наполнением статей без привлечения разработчика.

---

## 📋 Функциональные модули Сценария 2

### 1. Управление каталогом услуг и товаров (CRUD)
- [ ] **Список элементов:** Таблица с сортировкой, фильтрацией по статусу (`active`) и категориям.
- [ ] **Создание / Редактирование:**
  - Название, артикул/код.
  - Стоимость, старая цена (акция), валюта.
  - Краткое и подробное описание.
  - Порядок вывода (drag-and-drop или стрелки приоритета).
- [ ] **Быстрое переключение активности:** Toggle-переключатель видимости на сайте в 1 клик через HTMX (`hx-post="/client/services/{id}/toggle"`).

### 2. Загрузка и управление медиа (Галерея и Логотип)
- [ ] **Drag & Drop загрузчик:**
  - Загрузка логотипа сайта, фавиконки и фото владельца/компании.
  - Загрузка обложек для статей и карточек услуг.
  - Мгновенная генерация превью на Alpine.js.
  - Валидация типов файлов (WebP, PNG, JPEG) и ограничение по весу (до 5 МБ).
- [ ] **Интеграция с PocketBase File API:** Сохранение файлов напрямую в `pb_data/storage` с автоматическим обновлением записей в БД.

### 3. Отзывы клиентов и социальные доказательства (Social Proof)
- [ ] **Коллекция `testimonials` / `reviews`:**
  - Имя клиента, компания/должность, аватар/фото.
  - Текст отзыва, рейтинг (1–5 звезд).
  - Ссылка на источник (Яндекс.Карты, 2ГИС, Google, ProDoctorov).
  - Модерация: статус «Опубликован» / «Скрыт».

### 4. Визуальный редактор, отложенная публикация и корзина для блога
- [x] **Визуальный WYSIWYG-редактор:** Полноценный Quill.js в едином Dark Slate стиле, форматирование заголовков H2/H3, списков, цитат, жирного текста.
- [x] **Обложка статьи (Drag & Drop):** Интерактивная загрузка обложки на Alpine.js с предпросмотром, заменой и удалением (`cover_image`).
- [x] **Теги и рубрики:** Интерактивные чипсы тегов с быстрым добавлением и готовыми пресетами.
- [x] **Быстрое переключение активности:** Мгновенный тоггл публикации в 1 клик прямо из таблицы (`hx-post="/client/articles/toggle/{id}"`).
- [x] **Отложенная публикация (Scheduled Publishing):** Точный выбор даты и времени публикации (`<input type="datetime-local">`) с быстрыми пресетами («Сейчас», «Завтра в 09:00», «Через 3 дня», «Через неделю»). Автоматическое появление на сайте при наступлении срока и фоновый крон PocketBase для инвалидации кэша.
- [x] **Удаление через Корзину (Soft Delete):** Защита контента от случайного удаления: перемещение в корзину (`is_deleted`, `deleted_at`), вкладка «Корзина» со счетчиком, восстановление в 1 клик, окончательное удаление и полная очистка корзины.

### 5. SEO-настройки для страниц и статей
- [ ] Кастомный Meta Title и Meta Description с индикатором длины (зеленый/красный счетчик символов).
- [ ] Настройка Open Graph превью для соцсетей (VK, Telegram).
- [ ] Настройка канонических URL и тегов.

---

## 🛠 Архитектурные требования
- **Стек:** Go 1.27 + PocketBase v0.40 + Templ + HTMX + Alpine.js.
- **Производительность:** Сохранение In-Memory кэширования с точечной инвалидацией через хуки `OnRecordAfterUpdate`.
- **Изоляция:** Нулевые сторонние рантаймы (без Node.js в продакшене), компиляция всех UI-шаблонов в бинарник.
