# 📖 Руководство по архитектуре и файлам проекта

Данный документ содержит полное описание структуры проекта, назначение каждого файла и инструкции по тому, какие файлы нужно редактировать под конкретные задачи.

---

## ⚡ Быстрая шпаргалка: Что редактировать для...

| Задача | Где редактировать | Примечание |
|---|---|---|
| **Изменить телефон, адрес, ФИО нотариуса, график** | Админка PocketBase (`http://127.0.0.1:8080/_/` → `site_content`) | Либо в `internal/data/schema.go` (начальные значения по умолчанию) |
| **Добавить, удалить или изменить услуги/цены** | Админка PocketBase → коллекция `services` | Либо в `internal/data/schema.go` (начальные данные) |
| **Изменить дизайн / верстку шапки сайта** | `ui/components/header.templ` | После редактирования Templ перегенерируется автоматически через `air` |
| **Изменить дизайн первого экрана (Hero)** | `ui/components/hero.templ` | Бейдж, заголовки, фото нотариуса |
| **Изменить форму записи на приём** | `ui/components/booking.templ` | HTML-поля, селекторы даты/времени, валидация |
| **Изменить обработку заявок на бэкенде** | `main.go` (роут `/api/leads`) | Сохранение заявки, ответ HTMX, отправка уведомлений |
| **Изменить блок Яндекс.Карты или адреса** | `ui/components/map.templ` | Виджет карты, контакты |
| **Изменить режим доступности (для слабовидящих)** | `ui/components/a11y_bar.templ`, `ui/layouts/base.templ`, `ui/assets/input.css` | Кнопки управления и стили высокой контрастности |
| **Изменить цветовую палитру (бордовый, золото и др.)** | `tailwind.config.js` | Блок `colors.legal.*` |
| **Добавить глобальные стили или шрифты** | `ui/assets/input.css` (стили) и `ui/layouts/base.templ` (тег `<head>`) | Исходный CSS для компилятора Tailwind |
| **Добавить новый роут / страницу** | `main.go` (роут) и новая страница в `ui/pages/` | Вызов `pages.YourPage(...).Render(...)` |
| **Подключить уведомления в Telegram** | `internal/bot/` и вызов в `main.go` (внутри `/api/leads`) | Отправка лидов нотариусу в Telegram |
| **Настроить зависимости, пакеты, переменные окружения** | `devenv.nix` | Настройки Nix, Go, Templ, Tailwind CLI |

## 🏗 Общая архитектура проекта

Стек технологий:
- **Go 1.27 + PocketBase**: Ядро бэкенда, встроенная база данных SQLite, встроенная веб-панель администратора (`/_/`), система сессий и авторизации.
- **Templ**: Строго типизированный шаблонизатор HTML на Go. Шаблоны компилируются в нативный Go-код, обеспечивая высочайшую производительность и 100/100 SEO без Node.js на сервере.
- **HTMX**: Отправка форм (например, заявка на запись) и асинхронные запросы без перезагрузки страницы и без сложного JS.
- **Alpine.js**: Легковесная реактивность на клиенте (панель для слабовидящих, меню, модальные окна).
- **Tailwind CSS**: Утилитарные стили, компилируемые standalone-бинарником Tailwind CLI.
- **Air**: Демон для мгновенного перезапуска сервера и перегенерации шаблонов при сохранении файлов.

## 📂 Детальный обзор файлов и директорий

### 1. Корень проекта

- **`main.go`**  
  **Точка входа приложения.**  
  - Запускает PocketBase.  
  - На хуке `OnBootstrap` вызывает инициализацию базы данных (`data.InitSchema`).  
  - Настраивает роуты веб-сервера (`se.Router.GET("/", ...)`, раздачу статики `/assets/`, приём заявок `/api/leads`).  
  - **Когда редактировать:** при добавлении новых URL-адресов, изменении серверной логики обработки форм, подключении middleware или фоновых сервисов.

- **`devenv.nix`**  
  **Конфигурация окружения разработки (Nix/Devenv).**  
  - Определяет установленные пакеты (`go`, `templ`, `tailwindcss`, `air`, `sqlite`).  
  - Задает вспомогательные команды (`dev`, `build`, `gen:templ`, `build:css`).  
  - **Когда редактировать:** если нужно добавить утилиты, обновить версии пакетов или изменить скрипты запуска.

- **`devenv.yaml`** и **`devenv.lock`**  
  Служебные файлы блокировки версий пакетов Nix. Редактировать вручную не требуется.

- **`tailwind.config.js`**  
  **Конфигурация Tailwind CSS.**  
  - Задает пути сканирования классов (`./ui/**/*.templ`, `./ui/**/*.html`).  
  - Настраивает фирменные цвета проекта (`legal.burgundy`, `legal.gold`, `legal.light` и т.д.).  
  - **Когда редактировать:** при изменении корпоративных цветов, добавлении кастомных шрифтов или брейкпоинтов.

- **`.air.toml`**  
  **Конфигурация hot-reload для `air`.**  
  - Указывает, какие расширения отслеживать (`.go`, `.templ`), команды предварительной сборки (`templ generate && tailwindcss ...`), задержки и папки для исключения.  
  - **Когда редактировать:** если изменилась логика запуска live-reload или нужно исключить папки из наблюдения.

- **`go.mod`** и **`go.sum`**  
  Файлы зависимостей Go-модулей (`pocketbase`, `templ` и т.д.).

- **`README.md`**  
  Краткая справка по быстрому старту и базовым командам проекта.

- **`PROJECT_GUIDE.md`** *(этот файл)*  
  Подробная карта файлов и руководство разработчика по внесению изменений.

### 2. Директория `internal/` (Внутренняя логика бэкенда)

- **`internal/models/content.go`**  
  **Go-структуры данных (Data Models).**  
  - `SiteContent`: содержит поля для текстов первого экрана, телефонов, графика работы, адреса, ссылки на карту и фото.  
  - `ServiceItem`: структура услуги (заголовок, описание, стоимость, сортировка, активность).  
  - **Когда редактировать:** при добавлении в сайт новых динамических сущностей или дополнительных полей (например, email нотариуса, ИНН, ссылки на соцсети).

- **`internal/data/schema.go`**  
  **Инициализация коллекций PocketBase и работа с базой.**  
  - `InitSchema`: создает коллекции `site_content`, `services`, `leads`, если они ещё не существуют, и наполняет их дефолтными данными при первом старте.  
  - `GetSiteContent`: читает актуальные данные контента из PocketBase с фоллбэком на значения по умолчанию.  
  - `GetServices`: читает список активных услуг нотариуса, отсортированных по полю `order`.  
  - **Когда редактировать:** если требуется изменить структуру базы данных, добавить новые поля в коллекции или поменять начальные тексты для чистой базы.

- **`internal/handlers/`**  
  Директория для выноса сложных HTTP-обработчиков из `main.go` по мере роста проекта.

- **`internal/bot/`**  
  Директория для реализации Telegram-бота нотариуса (уведомления о новых заявках в чат/канал нотариуса, подтверждение записей).

### 3. Директория `ui/` (Интерфейс, шаблоны и стили)

#### `ui/layouts/`
- **`ui/layouts/base.templ`**  
  **Главный layout-шаблон всего сайта.**  
  - Содержит базовый HTML5 каркас: `<head>`, мета-теги SEO/OpenGraph, подключение Google Fonts, HTMX, Alpine.js и стилей `/assets/styles.css`.  
  - Содержит клиентскую логику режима доступности для слабовидящих (сохранение настроек в `localStorage`, переключение шрифтов, контрастности, цветовых схем).  
  - **Когда редактировать:** при изменении общих мета-тегов, добавлении сторонних аналитик (Яндекс.Метрика), подключении внешних библиотек или скриптов.

#### `ui/pages/`
- **`ui/pages/home.templ`**  
  **Шаблон главной страницы.**  
  - Собирает страницу воедино, размещая компоненты в правильном порядке: `A11yBar` → `Header` → `Hero` → `ScheduleBar` → `Services` → `Booking` → `MapSection` → `Footer`.  
  - **Когда редактировать:** при смене порядка секций на главной странице или добавлении новых блоков.

#### `ui/components/`
- **`ui/components/a11y_bar.templ`**  
  Панель для слабовидящих (ГОСТ/стандарт доступности): изменение размера шрифта (A-, A, A+), межбуквенного интервала, цветовых тем (черно-белая, бело-черная, синяя) и отключение картинок.
- **`ui/components/header.templ`**  
  Шапка сайта: логотип/герб нотариата, плашка режима работы, телефоны для быстрой связи, кнопка включения версии для слабовидящих, меню навигации.
- **`ui/components/hero.templ`**  
  Первый экран: официальный статус, имя нотариуса, фото, ключевое описание преимуществ и кнопка быстрой записи на приём.
- **`ui/components/schedule.templ`**  
  Информационный блок графика работы: дни и часы приёма, обеденный перерыв, выходные дни.
- **`ui/components/services.templ`**  
  Каталог нотариальных действий и услуг: карточки с наименованием, описанием и фиксированными тарифами/ценами.
- **`ui/components/booking.templ`**  
  Форма онлайн-записи на приём: выбор даты, доступных слотов времени, категории нотариального действия, ввод имени и телефона. Отправляет данные через HTMX на `/api/leads`.
- **`ui/components/map.templ`**  
  Контакты и локация: точный адрес, ориентиры, телефоны и интерактивная карта (Яндекс.Карты iframe).
- **`ui/components/footer.templ`**  
  Подвал: реквизиты, лицензия, ссылки на разделы, дисклеймер о правовом статусе нотариальных действий.

> ⚠️ **ВАЖНО ПРО ШАБЛОНЫ TEMPL:**  
> Все файлы с суффиксом `*_templ.go` (например, `booking_templ.go`) являются **автоматически генерируемыми**. **Никогда не редактируйте их вручную!** Редактируйте только соответствующие `.templ` файлы.

#### `ui/assets/`
- **`ui/assets/input.css`**  
  **Главный файл стилей.**  
  - Содержит директивы `@tailwind base; @tailwind components; @tailwind utilities;`.  
  - Содержит стили для режима слабовидящих (`html.a11y-mode`, фильтры контрастности, скрытие изображений) и кастомные скроллбары.  
  - **Когда редактировать:** если нужно добавить глобальные CSS-классы, анимации или специфические стили.
- **`ui/assets/styles.css`**  
  Скомпилированный файл стилей (генерируется Tailwind CLI). Редактировать вручную нельзя.
- **`ui/assets/images/`**  
  Папка для статических изображений (печати, герб, фото нотариуса).

### 4. Данные и сборка

- **`pb_data/`**  
  Встроенная база данных PocketBase (файлы `data.db`, `data.db-wal` и файлы загрузок).  
  Создается автоматически при первом старте приложения. В ней хранятся все записи из админки.
- **`bin/`**  
  Содержит скомпилированный бинарный файл `bin/server`, получаемый после запуска команды `build`.

## 🛠 Полезные команды разработки

Запуск команд внутри окружения `devenv shell` (или через `devenv shell <команда>`):

```bash
# 1. Запуск в режиме разработки с автоперезагрузкой (Air)
dev

# 2. Полная производственная сборка (Templ + Tailwind + Go Build)
build

# 3. Ручная перегенерация только шаблонов Templ
gen:templ

# 4. Ручная сборка и минификация стилей Tailwind
build:css

# 5. Режим отслеживания изменений стилей Tailwind в реальном времени
watch:css
```
